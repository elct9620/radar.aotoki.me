Being actively adopted now that the 2026-07-28 specification drops the session handshake for a stateless core: a server no longer needs sticky sessions or a shared session store, so it deploys onto ordinary HTTP infrastructure like any other endpoint. That removes the operational objection that kept it at arm's length, and makes granting an agent a new capability a matter of publishing one more small service.
