Proven as the language for anything that has to reach below the runtime: memory safety without a garbage collector holds up where C would otherwise be the only option. In practice it is where [WebAssembly](/platforms-and-services/webassembly/) sandboxes and native Ruby extensions get built, which is exactly the layer that is hardest to get right in a managed language.
