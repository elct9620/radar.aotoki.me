Now in active use as the sandbox for agent-generated code, following the [Harness Engineering](/methods-and-patterns/harness-engineering/) direction. The isolation is a property of the runtime rather than something the host has to enforce, which turns "let the model run this" from a security problem into a deployment detail — the reason it moved from assessment to real work.
